# 🚀 CloudBerry QA Automation Portfolio

QA Automation portfolio created during **CloudBerry's AI-Powered QA Automation Bootcamp**. Features end-to-end web automation using Java, Selenium WebDriver, TestNG, and Page Object Model (POM).

* **Target App:** [CloudBerry Store](https://cloudberrystore.services/)
* **Stack:** Java, Selenium WebDriver, TestNG, Maven, ExtentReports, Git

---

## 📅 Curriculum & Progress

### 🔹 Week 1: Java Basics & Git
* **Day 2:** Environment Setup (JDK, Eclipse) & Core Java Concepts (JVM, JRE, JDK).
* **Day 3:** Variables, Data Types & Conditionals → *Built Calculator & BMI Calculator*.
* **Day 4:** Logic & Loops → *Built Rock-Paper-Scissors game*; GitHub repository setup.

### 🔹 Week 2: Selenium WebDriver & Automation Fundamentals
* **Day 5:** Selenium WebDriver Architecture & Maven setup; automated browser launch & title validation (`TC01_LaunchApplication`).
* **Day 6:** Relative XPath strategies & Selenium Waits (`Implicit`, `Explicit`); automated user login flow (`TC02_Login`).
* **Day 7:** E-Commerce Workflows:
  * `TC03_AddToCart`: Category navigation, date selection, cart validation.
  * `TC04_CompletePurchase`: End-to-end checkout & order confirmation.
* **Day 8:** Java OOP: Classes, Objects, Methods, Constructors applied to test scripts.

### 🔹 Week 3: Frameworks, TestNG & Advanced Concepts
* **Day 10:** Data-Driven Testing (`@DataProvider`) & Parallel/Cross-Browser execution using `testng.xml` (`@Parameters`).
* **Day 11:** TestNG Listeners (`ITestListener`) & ExtentReports v5 integration with automated failure screenshots.
* **Day 12:** OOP Inheritance & Interfaces (contract-driven testing using `public static final` constants).
* **Day 13:** Page Object Model (POM) with Page Factory (`@FindBy` & `PageFactory.initElements`).
* **Day 14:** Test Framework Architecture: Modular, Data-Driven, and Hybrid strategies with test case prioritization (P1–P4).

---

## 🛠️ Tech Stack
* **Language:** Java
* **Automation:** Selenium WebDriver 4.x
* **Test Runner:** TestNG
* **Design Pattern:** Page Object Model (POM) / Page Factory
* **Build Tool:** Apache Maven
* **Reporting:** ExtentReports v5
* **Locators:** SelectorsHub, XPath, CSS

## ⚡ How to Run Tests

1. **Clone the repository:**
   ```bash
   git clone https://github.com/uzmashxxxikh/Cloudberry-Pojects.git
   cd Cloudberry-Pojects
   ```
2. **Execute tests via Maven:**
   ```bash
   mvn clean test
   ```
